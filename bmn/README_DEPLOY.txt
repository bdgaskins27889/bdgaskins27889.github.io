BARBWIRE MEDIA NETWORK LANDING PAGE

This folder is a self-contained landing page and does not require a custom domain.

FILES
- index.html = main landing page
- verify-BMN-001.html = credential verification page
- BMN_Press_Credential_Media_Dossier_v1.1.pdf = press dossier
- assets/ = BMN visual assets

HOW TO USE NOW
Upload the entire BMN_Landing_Page folder to any static website host. The host will provide a temporary/free URL. The same page can later be connected to a custom BMN domain without redesigning the page.

BEFORE PUBLIC LAUNCH
1. Add the live Facebook Page URL when available.
2. Decide whether to publish a dedicated newsroom email.
3. Replace the temporary host URL in the BMN-001 QR code after deployment.
4. Keep the credential disclaimer intact.

FUTURE FULL SITE
This landing page can become the home page. Add News, Investigations, Public Records, Interviews, Opinion, Culture, About, Standards, Corrections, Contact, and Press/Credentials sections as separate pages later.
